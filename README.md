# 🎮 Pokemon Legend 8.0

> Современная переписка легендарной браузерной МMORPG игры в покемонов на **PHP 8.3+** и архитектуру 2026 года

---

## 📋 Описание

**Pokemon Legend** – это браузерная многопользовательская ролевая игра, в которой игроки ловят, тренируют и сражаются покемонами. Проект прошел долгую эволюцию и теперь полностью переписывается на современный стек технологий.

### 🎯 Почему переписываем?

Старая кодовая база использовала:
- ❌ PHP 5.x с устаревшей архитектурой
- ❌ `mysql_*` функции (давно удалены из PHP)
- ❌ Frameset и iframe-based навигация
- ❌ Разделенная логика по 50+ PHP файлам
- ❌ `md5` для хширования паролей
- ❌ Несогласованная кодировка (ISO-8859-1)

Теперь строим:
- ✅ **PHP 8.3+** с типизацией и современным синтаксисом
- ✅ **PSR-4 автозагрузка** и namespaces
- ✅ **MVC архитектура** с контроллерами и сервисами
- ✅ **PDO** с подготовленными запросами (защита от SQL-injection)
- ✅ **JSON API** для фронтенда вместо HTML frameset
- ✅ **UTF-8** везде
- ✅ **CSRF защита** для всех действий

## 📦 Установка и запуск

### Требования
- PHP 8.3+
- MySQL 5.7+
- Composer

### Шаги установки

```bash
# 1. Клонируем репозиторий
git clone https://github.com/Mewt0/pokelegenda26.git
cd pokelegenda26

# 2. Установка зависимостей (если есть)
composer install

# 3. Создаем .env из примера
cp config/.env.example .env
# Редактируем конфиг БД, URL приложения и т.д.

# 4. Запускаем локальный сервер
composer run serve
# Доступно на http://127.0.0.1:8000
```

### Структура проекта

```
pokelegenda26/
├── public/               # Публичная точка входа
│   ├── index.php         # Front controller
│   ├── .htaccess         # Apache rewrite rules
│   └── css/              # CSS файлы
├── src/                  # Новый код (PSR-4 namespace: Pokemon8\)
│   ├── Controller/       # Контроллеры
│   ├── Service/          # Доменные сервисы
│   ├── Repository/       # Репозитории (доступ к БД)
│   ├── Database/         # Подключение к БД
│   ├── Game/             # Игровая логика
│   ├── Security/         # Сессии, CSRF, пароли, баны
│   ├── Http/             # Request/Response объекты
│   ├── View/             # Рендер шаблонов
│   └── Support/          # Утилиты (Env, Autoload)
├── views/                # Шаблоны (PHP)
├── config/               # Конфигурация приложения
├── database/             # Миграции и seed-ы (планируется)
└── ROADMAP.md            # Полный план переписывания
```
