`public/css/game-start.css`). Повтори его, не изобретай свой.

Разметка одного пустого состояния:

```html
<div class="dex-empty is-empty">
  <span>Ничего не найдено</span>
  <button type="button" class="ui-btn dex-empty-action" data-dex-reset>Сбросить поиск и фильтры</button>
</div>
```

Правила:

```css
.dex-empty { display: grid; gap: var(--space-2); justify-items: start; padding: var(--space-4); color: var(--text-2); }
.dex-empty.is-loading { opacity: .75; }
.dex-empty.is-error { color: var(--danger-text); }
.dex-empty-action { justify-self: start; }
```

Смысл трёх состояний:

* `is-loading` — идёт загрузка, действие не нужно;
* `is-error` — ошибка, цвет `--danger-text`, чтобы она не выглядела обычным сообщением;
* `is-empty` — данных нет. **Если есть что сбросить — дай ровно одну кнопку**, которая
  сбрасывает именно тот ввод, из-за которого список пуст. Если сбрасывать нечего
  (например «Выберите письмо из списка») — кнопки нет.

Кнопка — класс `ui-btn` из `components.css`, доступное имя, достижима с клавиатуры.

## 1. Почта

правило содержит **литеральный цвет**:

```css
.mail-empty-state { padding: 30px 12px; color: #6c7e96; text-align: center; font-weight: 800; }
```

Использования (номера строк приблизительные, найди по тексту):

* `els.list.innerHTML = \`<div class="mail-empty-state">${state.query ? 'Письма не найдены.' : 'В этой вкладке пока пусто.'}</div>\`;`
* `els.preview.innerHTML = '<div class="mail-empty-state">Выберите письмо из списка.</div>';`

Что нужно:

* убрать литерал `#6c7e96`, взять `var(--text-2)`;
* развести состояния модификаторами;
* для «Письма не найдены.» (то есть когда `state.query` не пуст) дать кнопку, которая
  очищает `els.search` и `state.query` и перерисовывает список. Используй существующие
  поля и функции рендера, новых состояний не заводи;
* «В этой вкладке пока пусто.» и «Выберите письмо из списка.» — без кнопки;
* кнопка должна работать и когда состояние отрисовано в панели деталей, и когда в списке:
  повесь делегированный слушатель на корень, а не на одну панель.
