# БРИФ: переписывание визуала PokemonChic

Общий документ для двух исполнителей — Codex и ChatGPT. Оба работают по нему,
чтобы получился **один** визуальный язык, а не два разных.

## Что за проект

Браузерная игра про тренеров покемонов. Стек: legacy PHP, обычные HTML/CSS/JS,
без сборки, без фреймворков, без препроцессоров. Стили — плоский CSS с токенами.

## Куда идём

Рефреш уже начат и держится на трёх вещах, ломать их нельзя:

1. **`public/css/tokens.css` — единственный источник значений.** Литеральные цвета,
   отступы, радиусы и кегли в правилах запрещены. Все новые правила берут только `var(--…)`.
2. **`public/css/components.css` — единый слой компонентов**, подключается на всех
   страницах после `base.css`. Там уже есть `.ui-btn`, `.ui-field`, `.ui-card`,
   `.ui-empty`, `.ui-toast`, `.ui-skeleton`, `.ui-overlay`.
3. **`public/img/ui/icons.svg` + `public/css/icons.css` — единая иконка.** Иконка это
   `<span class="icon icon--NAME" aria-hidden="true"></span>`, цвет берётся из
   `currentColor`. 34 символа, подключены 22 места.

## Что конкретно осталось

### A. Символы вместо иконок

Чеклист скила `ui-ux-pro-max` прямо запрещает «emoji as icons». Замерено: осталось
**60** мест, где иконкой служит типографский символ. Из них настоящие заглушки —
`▣ ⚑ ⚔ ◈ ○ ↻ ▶ ★ ✦ ✕ ☻ ⇩ ✧ ✓ ☆ ⚙`; их надо заменить на подходящие `.icon--*`.
**Не трогать:** `♂ ♀` (принятое в играх про покемонов обозначение пола), `→ ← « » ·`
(обычная типографика), `§` в комментариях.

Где именно (по убыванию количества):
`views/game-start.php` (12), `views/game-pokemon.php` (10), `public/js/quest-journal.js` (7),
`public/js/battle-dock-prototype.js` (7), `public/js/dex-overlay.js` (6),
`views/game-items.php` (6), `public/js/game-start-runtime.js` (5),
`public/js/player-menu.js` (2), `public/js/profile-settings-modal.js` (2),
`public/js/trainer-profile-window.js` (1), `views/game-events.php` (1),
`views/game-tournaments.php` (1).

Если под символ нет подходящего `icon--NAME` — **не выдумывай новый символ в спрайте**
(это отдельное решение и отдельная задача), а оставь как есть и перечисли в отчёте.

### B. Кегль тела ниже рекомендации

`tokens.css`: `--fs-400: 15px`, а базовый кегль тела рекомендуется **16px**.
Правка выглядит безобидно, но `--fs-400` задаёт тело на всех экранах, поэтому её
надо делать отдельным шагом, с проверкой каждого экрана на переполнение.

### C. Длительность перехода

`--dur-fast: 120ms` при рекомендации 150–300 мс для hover. Поднять до 150 мс.

### D. Доступность (уже закрыто, не ломать)

Контраст текста ≥ 4.5:1 (посчитан: заливка кнопки 5.17:1, акцентный текст 6.35:1),
тач-цели 44×44 на ≤640, `cursor: pointer` у кнопок глобально, `aria-label` у иконочных
кнопок, `aria-hidden="true"` у декоративных иконок.

## Правила для обоих

- Менять только свою зону, указанную в конкретной задаче.
- Ни одного литерального значения в правилах.
- Не переименовывать классы и `data-`атрибуты, на которые ссылается JS.
- Тексты по-русски, регистр предложением.
- Ничего не удалять, не коммитить, не пушить.
- Гейт после изменений: `php tools/open_test_regression.php --profile=quick --login=Tacos --password=REDACTED_USE_SMOKE_PASSWORD`
  — нужно **24/24**. Если параллельно работают другие агенты, гейт не запускать,
  его прогонит DSH-агент.

## Форма отчёта

Изменённые файлы, конкретные команды, их вывод, `git diff --stat`, риски, что осталось.
