## Дефект 1. `tools/beta_backup.php` не находит `mysqldump`

`findMysqlDump()` подставляет жёсткий путь `D:/OSPanel/modules/database/*/bin/mysqldump.exe`,
а установка на этой машине лежит на `E:`. На PATH `mysqldump` тоже нет.

**Фактическое поведение** (команда и вывод, снято на этой машине):

```
php tools/beta_backup.php
Warning: proc_open(): CreateProcess failed, error code: 2 in .../beta_backup.php on line 119
[beta_backup] Unable to start mysqldump.
exit=1
```

**Обход, который работает:**

```
php tools/beta_backup.php --mysqldump='E:\OSPanel\modules\database\MariaDB-10.5-Win10\bin\mysqldump.exe'
Backup created: .../storage/backups/pokemonchic_beta_20261009_064407.sql (8.84 MB)
exit=0
```

**Что сделать.** Не подставлять чужой корень, а определять его. Достаточно:
искать по обоим корням (`D:` и `E:`), либо взять корень OSPanel из окружения,
либо положиться на `DB_HOST`/порт и сообщить понятную ошибку с примером рабочего
вызова. Ошибка «mysqldump not found» должна печатать, **где искали**.

**Приёмка:** `php tools/beta_backup.php` без флагов создаёт файл бэкапа на этой
машине; при отсутствии `mysqldump` сообщение содержит список проверенных путей.

## Дефект 2. Смоук реапера не может пройти ни при какой БД

`tools/pve_stale_battle_reaper_smoke.php` на строке 44 открывает собственную
транзакцию, а на строке 57 вызывает `$reaper->reap(false)`, который внутри
(`src/Game/StalePveBattleReaper.php:51`) открывает **вторую**. PDO вложенных
транзакций не поддерживает.

**Проверено на этой БД отдельным скриптом:**

```
внешняя транзакция: активна
вложенная beginTransaction бросила: PDOException: There is already an active transaction
```

Исключение всплывает в `catch (Throwable)` смоука и записывается как
`exception = FAIL`. То есть **смоук красный всегда**, и имя базы тут ни при чём —
проверка имени `pokemon_test` (строка 20) была не единственным барьером.

**Что сделать.** Выбрать одно и записать выбор в отчёт:
* либо смоук не открывает внешнюю транзакцию, а сам убирает за собой
  синтетические строки (`DELETE`/`UPDATE` в `finally`);
* либо у реапера появляется режим «работать в уже открытой транзакции»,
  и тогда откат делает смоук.

**Важно:** правку `src/Game/StalePveBattleReaper.php` согласуй — это не твоя
зона по умолчанию. Если нужен второй вариант, напиши DSH-агенту, он владелец
спеки, и правка войдёт в `TASK-032`.

## Дефект 3 (мелкий). Барьер на конкретное имя БД

Строка 20 требует буквально `DB_DATABASE === 'pokemon_test'`.

**Владелец отказался от изолированной БД:** «нет смысла изолировать».
Поэтому жёсткое имя нужно заменить на **явное согласие**: запускать, если
`DB_DATABASE === 'pokemon_test'` **или** задан `REAPER_SMOKE_ALLOW_LIVE=1`.
Смоук и так транзакционный, так что опасный запуск остаётся осознанным
действием, а не случайным.

## Ограничения

* Работай только в `tools/**`. `src/**`, `views/**`, `public/**` — не твоя зона.
* Не удаляй синтетические данные «на глаз»: либо транзакция, либо явная уборка в `finally`.
* Прогон смоука на живой БД допустим **только** после бэкапа.
