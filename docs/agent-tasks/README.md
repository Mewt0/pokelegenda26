# docs/agent-tasks — протокол обмена задачами между агентами

Здесь живёт очередь задач между **DSH-агентом** (владелец дизайн-рефреша) и **Codex-агентом** (исполнитель). Правила проекта и границы владения файлами — в `AGENTS.md` (корень).

## Формат

| Файл | Кто пишет | Что внутри |
|---|---|---|
| `TASK-NNN-имя.md` | DSH-агент | Спека: контекст, зона, шаги, критерии приёмки, формат доказательств |
| `TASK-NNN-имя.report.md` | Codex-агент | Отчёт: файлы, команды, результат, риски; секцию `## Review` дописывает DSH-агент |
| `BOARD.md` | оба | Доска статусов (единственный источник истины по статусу) |

Статусы: `todo` → `in-progress` → `review` → `done` | `rework` | `blocked`.

## Как DSH-агент запускает Codex

```powershell
$codex = 'C:\Users\grut\AppData\Local\OpenAI\Codex\bin\5ea220ae823df3d7\codex.exe'
$root  = 'E:\OSPanel\domains\pokemonchic.com'

& $codex exec -C $root -s workspace-write `
  -o "$root\docs\agent-tasks\TASK-001-asset-registry-check.report.md" `
  'Выполни задачу docs/agent-tasks/TASK-001-asset-registry-check.md. Соблюдай AGENTS.md: не трогай файлы вне зоны задачи.'
```

- `--json` — события в stdout как JSONL (для разбора).
- `-o <file>` — последний ответ агента пишется в файл (это и есть отчёт).
- Продолжить диалог: `codex exec resume --last "<дополнение>"`.
- Написать в уже запущенную сессию: `codex queue "<сообщение>"`.
- Песочница: `-s read-only` для задач-исследований, `-s workspace-write` для правок в проекте.

## Как Codex отчитывается

Отчёт пишется в `TASK-NNN-имя.report.md` по шаблону:

```markdown
# TASK-001 — отчёт

Статус: done | blocked
Изменённые файлы: <пути>
Команды и результаты:
- `<команда>` → <результат>
Проверки: php -l ... / smoke ...
Что осталось / риски: ...
```

## Как DSH-агент принимает работу

1. `git status` + diff только по зоне задачи.
2. Свои проверки (см. `AGENTS.md` §2).
3. Дописывает в report секцию `## Review` с вердиктом `done` или `rework` + замечания, обновляет `BOARD.md`.

## Правила

- Одна задача — одна зона файлов. Пересечения зон между одновременными задачами запрещены.
- Задача без критериев приёмки и формата доказательств не выдаётся.
- Если задача требует тронуть файл из чужой зоны — исполнитель останавливается и пишет `blocked` с объяснением.
