# TASK-020 — P1: «залипающие» экраны фронтенда (обработка ошибок сети)

**Исполнитель:** Codex-агент · **Зона (явно разрешена):** `public/js/mail-overlay.js`, `public/js/quest-journal.js`, `public/js/commission-market.js`, `views/game-items.php` · **Статус:** todo

> Зона `public/js/**` и `views/**` по `AGENTS.md` принадлежит DSH-агенту. Эта задача — явное исключение на перечисленные файлы. **Не трогай `public/js/game-start-runtime.js`** (его параллельно правит DSH-агент) и никакие другие файлы.

## Проблемы (подтверждены сканом фронтенда)

1. `public/js/mail-overlay.js:239-246` — `state.loading = true` → `await fetch(...)` без `try/catch`; `state.loading = false` только на успешной строке. Любая сетевая ошибка оставляет `loading = true`, и все последующие вызовы выходят раньше → **почта больше не загружается до перезагрузки страницы** («Загружаю почту…» навсегда).
2. `public/js/quest-journal.js:290-295` — та же ошибка в загрузке журнала квестов → «Загружаю журнал…» навсегда.
3. `public/js/commission-market.js:118-124` (хелпер `post()`) и вызовы `:504-525`, `:550-561` — нет `try/catch`, кнопка выключается **до** запроса. При сбое сети строки `button.disabled = false` / `submit.disabled = false` не выполняются → **кнопки «Купить»/«Снять»/«Выставить» навсегда заблокированы**.
4. `views/game-items.php:262-268` (`postInventoryAction`) и `:465` (`loadPage(1)`) — без `catch` и без проверки `response.ok`: при сбое инвентарь остаётся пустым/старым **без сообщения**, экипировка молча не срабатывает. Обработчики кнопок `:429-432` — то же.

## Что сделать

1. Привести каждое из перечисленных мест к виду: `try { … } catch (e) { показать понятную ошибку игроку } finally { снять блокировку/спиннер }`.
2. Ошибку показывать рядом с действием (в существующем UI-элементе этого файла: тост/статус/строка ошибки), текст — по-русски и по делу («Не удалось загрузить почту. Попробуйте ещё раз»). Не использовать `alert()`.
3. `response.ok` проверять перед `response.json()` там, где сейчас не проверяется.
4. Поведение при успехе не менять: те же запросы, те же данные, те же DOM-обновления.
5. Не рефакторить файлы целиком и не менять разметку, кроме добавления элемента для текста ошибки, если его нет.
