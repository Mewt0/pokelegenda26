# TASK-001 — Asset registry checker

**Исполнитель:** Codex-агент · **Зона:** `tools/**` · **Статус:** todo

## Задача

Сделать CLI-инструмент `tools/asset_registry_check.php`, который находит **ссылки на локальные ассеты, которых нет на диске**, и **ассеты, на которые никто не ссылается**. Сейчас в `VISUAL_ASSETS_TODO.md` числится 42 запланированных иконки, на диске 8; ловить такие расхождения вручную нельзя.

## Что сканировать

Источники ссылок:

- `views/**/*.php`, `public/index.php`
- `public/js/**/*.js`, `script/**/*.js`
- `public/css/**/*.css`

Искать:

- в PHP/HTML: `src="..."`, `href="..."`, `url(...)` внутри `style="..."`
- в CSS: `url(...)`
- в JS: строковые литералы, начинающиеся с `/public/`, `public/`, `img/`, `assets/`

Игнорировать:

- внешние и не-файловые: `http://`, `https://`, `//`, `data:`, `#`, `mailto:`, `tel:`, `javascript:`, `blob:`
- динамические: содержащие `<?=`, `{{`, `${`, `'+`, `" +`, `%s`
- фрагменты и query: всё после `#` и `?` отбрасывать
- legacy-каталоги `include/**`, `admin/**`, `css/**`, `img/**`, `pok/**`, `new_diz*/**`, `downloaded_*/**` — не сканировать как источники ссылок

## Что считать

1. **Битые ссылки** — путь резолвится в несуществующий файл. Вывод: `файл-источник:строка → путь`.
2. **Сироты** — файлы в `public/img/**` и `public/css/**`, на которые нет ни одной ссылки. Вывод: путь + размер. Это informational, не ошибка.

## CLI

```text
php tools/asset_registry_check.php [--json] [--strict] [--ignore-orphans] [--root=<path>]
```

- без флагов: человекочитаемый вывод, код возврата 1 если есть битые ссылки, иначе 0;
- `--json`: машиночитаемый отчёт `{broken:[{source,line,target}], orphans:[...], stats:{...}}` в stdout;
- `--strict`: битые ссылки + сироты дают код 1;
- `--ignore-orphans`: не считать сирот в статистике.

Требования к коду: PHP 8.1, `declare(strict_types=1)`, без внешних зависимостей, работает из корня проекта и из любого cwd (корень определяется от `__DIR__`), читает только файлы, ничего не пишет.

## Критерии приёмки

1. `php -l tools/asset_registry_check.php` — без ошибок.
2. Запуск из корня проекта печатает реальный список битых ссылок и сирот; код возврата соответствует контракту (проверить `echo $LASTEXITCODE`).
3. `--json` отдаёт валидный JSON (проверить `ConvertFrom-Json`).
4. Время работы на этом проекте — меньше 30 секунд.
5. Инструмент не меняет ни одного файла (`git status` после запуска — только добавленный файл инструмента).

## Доказательства в отчёте

- Команды и их вывод (сокращённо), включая код возврата.
- Итоговые числа: сколько битых ссылок, сколько сирот, топ-20 имён.
- Путь к полному JSON-выводу, если сохранял (сохранять вне проекта — в `%TEMP%`).
- Список битых ссылок привести целиком, если их меньше 40, иначе топ-40.
