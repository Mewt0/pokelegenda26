Теперь перед прикреплением вызывается `ensure_ready()`. (3) Проверка имени шла по `document.body.innerText`, который не видит скрытое и обрезанное; переведено на `textContent` и сравнение по стему — заодно выяснилось, что **ChatGPT переименовывает повторные загрузки** (`attach-test.md` → `attach-test(3).md`), поэтому полное имя искать нельзя. **Зависание устранено:** ожидание по умолчанию было 300 с, то есть прогон мог встать на пять минут; снижено до 45 с, и при неготовности вложений команда **отказывается отправлять** (код 6), а не шлёт текст без файлов. **Попутно в этих же раундах закрыты три дефекта параллельной рассылки:** движок брал первую попавшуюся вкладку (обе задачи для ChatGPT уходили в DeepSeek); две параллельные задачи печатали в один композер (обе отчитывались «2860 символов» — это сумма двух промптов); ChatGPT восстанавливает черновик в новой вкладке и проверка «диалог пуст» падала на остатках. Итого механика вложений работает, но потребовала четырёх исправлений, каждое из которых находилось только измерением на живой странице.
