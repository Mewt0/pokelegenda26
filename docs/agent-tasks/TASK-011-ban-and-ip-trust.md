## Проблемы (подтверждены аудитом)

1. **IP-бан не срабатывает вообще.** `src/Repository/BanRepository.php:19` — `SELECT ip FROM banip WHERE ip = :ip`, где `:ip` — строка `1.2.3.4` из `src/Support/ClientIp.php:11-21`. Колонка `banip.ip` — `int(11) unsigned`, записывается целым (`src/Repository/AdminRepository.php:544` `(int) ($user['ip'])`, `src/Repository/ChatRepository.php:241`). MySQL приводит `'1.2.3.4'` к `1`, поэтому `BanGuard::check()` (`src/Security/BanGuard.php:23-26`) почти никогда не находит бан.
2. `src/Repository/AdminRepository.php:561,564` — `INSERT INTO banip` и `audit()` без транзакции: бан есть, записи в журнале нет (или наоборот при откате).
3. `src/Support/ClientIp.php:11-21` — `X-Forwarded-For`, `X-Client-IP`, `X-Real-IP` принимаются без проверки доверенного прокси. Этот IP определяет бан и пишется в `users.ip` и в аудит → обход бан-листа и подстановка чужого IP.
4. `src/Security/BanGuard.php:19` — docblock испорчен двойной кодировкой (байты `Р•СЃР»Рё` вместо «Если»), подтверждено побайтовой проверкой.
