# Технический release candidate — 2026-10-24

Статус: технический baseline подготовлен; публичный production-релиз не выполнялся. По следующему поручению владельца до финальной UI-приёмки предстоит исправить и обновить профиль и почту. Большой backlog не объявлен автоматически закрытым.

## Исправлено

1. `NpcDialogService` больше не интерпретирует клиентские номера квеста/этапа как произвольную запись. Десять точных команд привязаны к серверным NPC и локациям. Narrative-переход атомарно проверяет ожидаемый этап, не завершает квест и не пропускает сдачу предметов/покемонов. Повторные старые кнопки безопасны и не откатывают прогресс.
2. `StalePveBattleReaper` исключает боссов при выборе, блокировке и финальном UPDATE; сохраняет свежие бои и PvP; снимает только соответствующий PvE-указатель. Завершение убирает Helping Hand и активные трансформации. При неверном deadline применяется TTL7200 от известного времени создания; неизвестный возраст сохраняется. Integrity использует тот же предикат.
3. После backup завершены 175 просроченных обычных PvE. Повторный dry-run: candidates=0, changed=0. Ничего из имущества игроков не удалялось. Для восстановления старого состояния сохранён backup до операции.
4. PHP8.5.11 включён для web и CLI, Default-профиль OSPanel обновлён. MySQL5.5:3308 и Nginx/Apache работают. Резервная копия профиля: `E:/OSPanel/userdata/profiles/Default.ini.before-release-20261024.bak`.
5. Убраны устаревшие `curl_close()` из QA-инструментов. Regression runner читает объединённый поток stdout/stderr: предупреждения PHP больше не могут заблокировать дочерний процесс на заполненной stderr-pipe.
6. `ErrorHandler` регистрируется до загрузки конфигурации/БД; исключения и fatal получают безопасный ответ и идентификатор записи в `log_php_errors.txt`. API404 возвращает JSON404; обычный HTML404 сохранён. После отправленных заголовков ошибка только логируется. Успешные API-контракты не менялись.
7. Изменяющие QA seed-операции запрещены в production даже при QA_TOOLS_ENABLED=1. В других окружениях нужен явный флаг. Убран стандартный пароль создаваемых аккаунтов: используется явно заданный QA_SEED_PASSWORD либо случайный секрет. Существующие пароли не менялись. Локальный `.env` явно помечен local/QA; он не входит в архив.
8. Apache запрещает внутренние каталоги, временные QA-страницы, архивы, дампы, логи и локальные служебные файлы. Nginx получил тот же запрет ДО regex-раздачи статики, иначе `/docs/*.js` обходил бы .htaccess. Поддерживаемый фрагмент: `config/deploy/nginx-protection.conf`; при регенерации конфигурации OSPanel его include нужно сохранить/восстановить.
9. `tools/build_release.php` собирает отдельный snapshot рабочего дерева, включая необходимые незакоммиченные runtime-файлы, с SHA256-манифестом. Исключены `.env`, backup, docs, tools, агентские каталоги, `_incoming`, `_qa-*`, прототипы, исторические архивы. Исходные файлы не удалялись; zip не является Git-тегом или доказательством опубликованного релиза.
10. В PROJECT_CONTEXT, BETA_RELEASE_TASKS, REWRITE_STATUS, README и BOARD добавлен актуальный датированный срез. Старые записи и спеки сохранены как история.
