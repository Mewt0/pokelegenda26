# PokemonChic

Браузерная RPG о мире покемонов: команда, ловля, PvE/PvP, NPC, квесты, торговля и путешествия между регионами. В этом репозитории идёт перенос старых PHP-страниц в новый игровой интерфейс с JSON API.

## Игровой мир

<p><img src="img/room/generated-20261025/alabastia.webp" alt="Обновлённая Алабастия" width="49%"> <img src="img/room/generated-20261025/arena-water.webp" alt="Водный стадион" width="49%"></p>

- **Путешествия:** локации, NPC, сюжетные задания, корабли и самолёты.
- **Команда:** ловля, питомник, яйца и разведение покемонов.
- **Бои:** PvE и PvP, атаки, предметы, история и повторы.
- **Экономика:** инвентарь, магазины и комиссионная лавка.
- **Общение:** чат, почта, друзья, карточки тренеров, события и турниры.
- **Управление:** GM Center для контента, модерации, выдач и QA.

При обновлении графики подключены новые фоны ко всем **155 локациям**, подготовлены **42 значка** NPC, переходов и справочников. Похожие биомы используют общие иллюстрации. Спрайты покемонов сохранены. Для 176 ID предметов подключены новые рисунки; остальные используют совместимые прежние изображения. Прокачка учитывает шесть групп роста с единой шкалой в бою, команде и инвентаре.

## Технологии

**PHP 8.5 · MySQL · vanilla JavaScript · CSS · JSON API**

Контроллеры принимают запросы, игровые сервисы выполняют правила, репозитории работают с БД. Представления и JavaScript отвечают за интерфейс.

```text
public/index.php       Вход в игру и API
src/Controller/        HTTP-контроллеры
src/Game/              Игровая логика
src/Service/           Прикладные сервисы
src/Repository/        Работа с БД
views/                 PHP-представления
public/js/, css/       Интерфейс
database/migrations/   Миграции
tools/                 Проверки, backup и обслуживание
```

Legacy-файлы ещё участвуют в отдельных сценариях и главной странице. Их удаление требует проверки зависимостей.

## Локальный запуск

Нужны PHP 8.5, Apache с `mod_rewrite`, расширения PDO MySQL и mbstring. Текущая локальная БД работает на MySQL 8.4.13; MySQL 5.5 сохранён только для отката; инструментам QA также нужны curl, GD и zip.

```bash
git clone https://github.com/Mewt0/pokelegenda26.git
cd pokelegenda26
cp .env.example .env
```

Укажите свои настройки БД и сессий в `.env`. Миграции расширяют существующую схему игры; рабочие дампы игроков и пароли в репозиторий не входят.

Подробности: [запуск и окружение](docs/GETTING_STARTED.md), [QA и регрессия](docs/TESTING.md).

## Статус

Проект развивается. GitHub Actions проверяет синтаксис и отдельные статические ограничения. Зелёный CI не подтверждает готовность production, все сюжетные ветки и длительные PvP-сессии.

Архитектура описана в разделе [«Технологии»](#технологии), порядок разработки — в [инструкции](docs/GETTING_STARTED.md#development).
