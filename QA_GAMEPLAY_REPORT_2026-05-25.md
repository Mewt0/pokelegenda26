# QA gameplay report 2026-05-25

Статус: первый реальный прогон закрыт, тестовый дроп выключен после проверки.

Цель: активный игровой прогон основного цикла Pokemon 8.0: PvE бой, дроп, магазин, предметы, лечение, питомник, квесты, награды, сохранение состояния и визуальная проверка UI.

## Тестовый режим

- Тестовый дроп включается командой `php tools/qa_drop_mode.php on 90 85`.
- Тестовый дроп выключается командой `php tools/qa_drop_mode.php off`.
- Скрипт создаёт временный x20 drop boost через `game_event_boosts` и QA-правила в `admin_drop_rules` для перьев `13`/`14`.
- Все QA-строки помечены `QA_TEMP_GAMEPLAY_DROP`, чтобы их можно было безопасно отключить.

## Проверенные сценарии

- PvE: старт debug-боя, атака, смена покемона, победа, завершение.
- Ловля: неудачная попытка обычным покеболом, успешная ловля Masterball QA.
- Боевые предметы: лечение кексом, отказ Энергетика без сна.
- Статусы: Toxic + тик отравления по HP.
- Дроп: QA-правила с высоким шансом, выдача перьев 13/14.
- Магазин: покупка покебола, списание монет.
- Инвентарь: категории `Квестовые` и `Дроп`, счётчики после боя.
- Покецентр: восстановление HP/PP.
- Питомник: новый overlay `/game/pokemon` показывает команду и 11 покемонов питомника.
- События: `happiness x3`, `drop x20`, интеграция `catch`.

## Backend-проверки

- `chats.id` уже `AUTO_INCREMENT`, `author_id` есть.
- После ловли Pidgeotto создан в `pok_user`, стартовые атаки добавлены в `attac_my_poke`.
- После лечения активная команда получила full HP, PP Chandelure восстановлены.
- После `ack-end` PvE бой удаляется из временных таблиц, но архив появляется в `battle_history_archive`.
- Нотификации наград создаются в `game_notifications`.
- QA-дроп и QA-буст счастья после прогона выключены/удалены; временные правила `QA_TEMP_GAMEPLAY_DROP` оставлены в БД отключенными для следующего тестового включения.
