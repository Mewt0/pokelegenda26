# Стандарт Pokemon 8.0

Новая версия пишется с нуля. Старые файлы используются только как справочник бизнес-логики.

## Целевая платформа

1. PHP 8.3+.
2. MySQL/MariaDB через PDO.
3. UTF-8 без BOM.
4. Один публичный вход: `public/index.php`.
5. Код приложения: `src/`.
6. Конфиги: `config/` + `.env`.
7. Шаблоны: `views/`.

## Правила кода

1. `declare(strict_types=1);` во всех новых PHP-файлах.
2. Namespace `Pokemon8\...`.
3. Никаких `mysql_*`, `mysqli_*` в бизнес-коде.
4. SQL только через репозитории.
5. Ввод только через `Request`.
6. Вывод только через escaping `View::e()`.
7. Сессии только через `Security\Session`.
8. Пароли новых пользователей - только `password_hash()`/`password_verify()`. Старый MD5-хэш допускается только как миграционный слой для существующих аккаунтов.
9. Никаких хардкоженных паролей, доменов и секретов в PHP.
10. Старые include-файлы не подключаются из нового ядра напрямую.

## Статусы папок

1. `public/` - новая публичная точка входа.
2. `src/` - новое приложение.
3. `config/` - новые конфиги.
4. `views/` - новые шаблоны.
5. `_incoming/` - донорские файлы, не production.
6. `include/`, `admin/`, старые root PHP - legacy/reference до переноса.

## Запуск

```powershell
php -S 127.0.0.1:8000 -t public public/index.php
```

После установки Composer можно использовать:

```powershell
composer dump-autoload
composer run serve
```
